# netflix-data-analysis


Project Overview

This project analyzes Netflix Movies and TV Shows using Python.

The project uses:

Pandas
NumPy
Matplotlib
Scikit-Learn
Dataset

Netflix Titles Dataset containing information about:

Movies
TV Shows
Release Year
Rating
Country
Genre

Objectives
Data Cleaning
Exploratory Data Analysis
Visualization
Machine Learning Classification

Technologies Used
Python
Jupyter Notebook
Pandas
NumPy
Matplotlib
Scikit-Learn

Key Insights
Movies dominate Netflix content.
Content production increased significantly after 2015.
The United States contributes the highest number of titles.
Machine Learning

A Random Forest Classifier was used to predict content type.
